# Research Questions

This project addresses the following questions:

- How should a UGC platform determine the recommendation intensity of pure content when consumers have reference-quality effects?
- How should a content creator dynamically adjust pure content quality over time?
- How do pure content quality and recommendation intensity interact with each other?
- How does dynamic decision-making affect platform and creator profits relative to static decision-making?
- How does uncertainty in consumer reference quality change content strategies and profitability?
- How should platforms balance user engagement from pure content against revenue generated by shoppable content?
