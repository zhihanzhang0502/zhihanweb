# Dynamic Control on UGC Platforms

This project studies how user-generated content platforms should dynamically balance pure content quality and recommendation intensity when consumer reference-quality effects are present.

## Project Overview

User-generated content platforms increasingly rely on a mixed content ecosystem, where pure content attracts and retains users, while shoppable content generates commercial revenue. This project develops a dynamic analytical model to study how a UGC platform and a content creator make strategic decisions over time.

The model focuses on the interaction between pure content quality, platform recommendation intensity, user engagement, and consumer reference quality. It compares static decisions, dynamic decisions without uncertainty, and dynamic decisions with stochastic reference-quality uncertainty.

## Research Questions

- How should a UGC platform determine the recommendation intensity of pure content?
- How should a content creator adjust pure content quality over time?
- How does consumer reference quality affect user engagement and platform profitability?
- How does uncertainty in reference quality change the strategies of platforms and creators?

## Methodology

The project uses game-theoretic modeling, optimal control theory, and differential games. It analyzes three scenarios:

1. Static pure content quality and recommendation intensity.
2. Dynamic quality and recommendation intensity without reference-quality uncertainty.
3. Dynamic decision-making with stochastic reference-quality uncertainty.

Numerical simulations are used to illustrate the optimal paths of reference quality, content quality, recommendation intensity, user engagement, and profit outcomes.

## Main Findings

- Dynamic strategies can increase UGC platform profits compared with static decisions.
- Dynamic decision-making may reduce content creators' earnings relative to a static environment.
- Higher uncertainty in reference quality may reduce platform profits but create opportunities for content creators.
- When reference-quality uncertainty is higher, the platform should increase pure-content recommendation intensity, while creators may reduce content quality.
