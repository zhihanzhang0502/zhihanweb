# State-Dependent DEX–CEX Price Discovery

## Overview

This project studies how information is transmitted from decentralized exchanges to centralized exchanges and how this transmission changes across blockchain and market conditions.

Using high-frequency trading data from Uniswap and Binance, the project examines whether DEX net trade flow predicts short-horizon CEX returns, whether Ethereum network congestion strengthens this relationship, and whether weak CEX liquidity reduces the efficiency of cross-market information transmission.

My work included collecting and processing high-frequency cryptocurrency data, constructing a two-minute DEX–CEX panel, engineering order-flow and liquidity variables, designing regression specifications with interaction terms and fixed effects, interpreting the empirical results, and preparing the final report and presentation.
