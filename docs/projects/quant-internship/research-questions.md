# Research Questions

This internship focused on the following questions:

- Do the available quantitative signals contain predictive information about subsequent futures returns?
- Which signal transformations and engineered features provide more stable cross-sectional predictive power?
- How should factor values be converted into long-short portfolio positions?
- How do ranking thresholds, position normalization, and smoothing windows affect portfolio performance?
- Can rolling regression and machine-learning models improve out-of-sample signal prediction?
- How should candidate strategies be compared using return, drawdown, win-rate, and stability measures?
